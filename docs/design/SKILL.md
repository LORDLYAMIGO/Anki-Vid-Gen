# Design brief

Use the project [SKILL.md](../../SKILL.md) and section 14 of [plan.md](../../plan.md) when changing visual components. The default `washi-editorial` theme uses warm paper, ink and restrained vermilion. Keep the card content central, use empty space for hierarchy, and use no cultural decoration as a shortcut for Japanese editorial design.

Preview and export must use the same `FlashcardVideo` component and integer frame plan. Theme, layout and motion may change appearance but never narration or reveal timing. Check Latin, Japanese and Devanagari samples and keep the phone safe area readable. A card that cannot fit should be flagged for review instead of clipped silently.
